# Contributing

## ✅ Contribution Scope
Contributions are welcome for:
- firmware stability improvements
- code readability and refactoring
- performance profiling
- test coverage and validation scripts
- documentation quality

## 🔍 Before You Open a PR
1. Build successfully with `./build_auto.sh`.
2. Keep commits focused and atomic.
3. Update docs if behavior changes.
4. Respect legal/ethical usage constraints.

## 🧪 Suggested Validation
- Compile check on clean environment
- Runtime smoke test on ESP8266
- Verify scan/attack state transitions via serial output
- Verify LED behavior against docs

## 🧾 Commit Style
Use concise commit messages:
- `feat: ...`
- `fix: ...`
- `docs: ...`
- `refactor: ...`
