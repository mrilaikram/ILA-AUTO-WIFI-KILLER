# Security Policy

## Intended Use
This project is for authorized wireless security testing and education in controlled environments.

## Prohibited Use
- Unauthorized disruption of third-party networks
- Any activity violating local laws, regulations, or contractual rules

## Reporting
If you discover vulnerabilities, unsafe defaults, or accidental data exposure risks, open a private report with:
- clear reproduction steps
- affected files/modules
- proposed mitigation (if available)

## Sensitive Data Handling
Do not commit:
- personal access tokens
- private keys
- personal device credentials
- machine-specific absolute paths
